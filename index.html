PERIMETER POST

The authorization checkpoint for kar-hub. An operator issues a capability — who may do what, a budget, an expiry — and the post lets a request through only if it is operator-signed, holder-signed, in scope, unexpired, unrevoked, in budget, and not a replay. booting kernel…

A packet gate asks “is this well-formed and authentic?” — this asks “is this agent authorised and in budget for THIS action, right now?” Everything below runs the exact decide kernel the tests and CI gate; the operator and agent keys are generated in your browser.
